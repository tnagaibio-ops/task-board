# 学生スタッフ｜当日タスクボード

学生がスマホで「状況（未着手／対応中／完了／保留）」を変更し、職員は Google スプレッドシートでタスクを管理するシステムです。

```
学生のスマホ ──▶ GitHub Pages（この画面） ──▶ Google Apps Script ──▶ スプレッドシート
                                                                    ▲
                                                 職員がシートを直接編集 ┘
```

- **職員**：スプレッドシートにタスクを書く・直す・消す（これまでの Excel と同じ感覚）
- **学生**：QR から開いて、ボタンで状況を変えるだけ（誰がいつ変えたか自動記録）
- 画面は 20 秒ごとに自動更新。変更はすべて「ログ」シートに残る

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `app.js` / `style.css` | 学生用スマホ画面 |
| `config.js` | GAS の URL を書く設定ファイル（**ここだけ編集**） |
| `qr.html` | 職員用：アクセスコード入り QR を作って印刷 |
| `gas/Code.gs` | スプレッドシートに貼る Apps Script |
| `lib/qrcode.js` | QR 生成ライブラリ（MIT） |

## セットアップ（初回のみ・約15分）

### 1. スプレッドシートと Apps Script
1. Google ドライブで新しいスプレッドシートを作成（名前例：`当日タスクボード`）
2. メニュー「拡張機能」→「Apps Script」
3. 最初からある `コード.gs` の中身を全部消し、`gas/Code.gs` の内容を貼り付けて保存
4. 上部の関数選択で **`setup`** を選び「実行」→ 権限の確認で自分のアカウントを許可
   - 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」
5. スプレッドシートに `タスク` `設定` `ログ` シートができます（元の Excel の11件がサンプルで入ります）
6. `設定` シートの **アクセスコード**（4桁の数字）を控えておく

### 2. ウェブアプリとして公開
1. Apps Script 画面右上「デプロイ」→「新しいデプロイ」
2. 種類の選択（歯車）→「ウェブアプリ」
3. 次のとおり設定して「デプロイ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピー

### 3. GitHub に置く
1. GitHub で新しいリポジトリを作成（例：`task-board`）
2. `config.js` の `GAS_URL: ''` の `''` の中に、手順2でコピーした URL を貼る
3. このフォルダの中身をすべてアップロード（「Add file」→「Upload files」でドラッグ＆ドロップ可）
4. リポジトリの「Settings」→「Pages」→ Branch を `main` / `/ (root)` にして Save
5. 1〜2分後、`https://<ユーザー名>.github.io/task-board/` で開けるようになります

### 4. QR を作って配布
1. `https://<ユーザー名>.github.io/task-board/qr.html` を開く
2. アクセスコードを入力 →「QRを作成」→「印刷」
3. 学生は QR を読むだけで開けます（コード入力不要。一度開けばスマホに記憶されます）

## 日々の運用（職員）

| やりたいこと | 操作 |
|---|---|
| タスクを追加 | `タスク` シートの下の行に「やること」を書く（No. は空欄でも自動で振られます） |
| タスクを修正 | そのままセルを書き換える（学生の画面には20秒以内に反映） |
| タスクを消す | 行を削除 |
| 学生に全体連絡 | `設定` シートの「お知らせ」に書く（画面上部に黄色で表示）。消せば非表示 |
| 担当を指定 | 「担当」列に名前やグループ名を書く |
| 職員が状況を変える | シートの「状況」をプルダウンで変更（最終更新者に「職員（シート）」と記録） |
| 次の開催日の準備 | メニュー「タスクボード」→「状況をすべて『未着手』に戻す」 |
| 誰が何をしたか確認 | `ログ` シート |

- 列の順番は入れ替えても動きます（見出し名で判定）。見出しの文字だけは変えないでください。
- 「優先度」は 高 → 通常 → 低 の順に並び、完了したタスクは一番下に移動します。
- 締め切りは日付でも「朝礼まで」のような文字でも OK です。

## アクセスコードについて

- GitHub Pages の URL は誰でも見られるため、アクセスコードで保護しています。コードがないとタスクは表示されず、変更もできません。
- QR が外部に出回ったら、`設定` シートのアクセスコードを変えて QR を作り直してください（古い QR は即無効）。
- 個人情報・機微情報はタスクに書かないでください。

## Code.gs を修正したとき

「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」。
（「新しいデプロイ」にすると URL が変わってしまうので注意）

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| 「接続できません」 | `config.js` の URL が `/exec` で終わっているか確認。デプロイの「アクセスできるユーザー」が「全員」か確認 |
| 毎回アクセスコードを聞かれる | ブラウザのプライベートモードでは記憶されません。通常モードで開く |
| シートを直したのに画面が変わらない | 右上の更新ボタンを押す（自動更新は20秒ごと） |
| デモ表示のまま | `config.js` に URL が入っていない。GitHub 上の `config.js` を確認 |

※ 学校の Google Workspace アカウントで作る場合、管理者設定で「全員」に公開できないことがあります。その場合は管理者に「Apps Script ウェブアプリの外部公開」を許可してもらってください。
